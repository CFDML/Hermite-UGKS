# ugks2d - Hermite UGKS validation solver

This source tree runs the Poiseuille and quarter-domain Rayleigh--Taylor
benchmarks from `ugks_hermite.pdf`.  The validation supplied here uses only
Gauss--Hermite quadrature and the Hermite force expansion.

Three Hermite implementations are available.  `force_type='hermite'`
preserves the original product-basis routine.  `force_type='hermite_symmetric'`
uses the corrected two-dimensional independent-component contraction through
\(d^{(n)}\).  `force_type='hermite_symmetric_b'` evaluates the same force by
first forming the normalized symmetric tensor
\(b^{(n+1)}=\operatorname{Sym}(a\otimes d^{(n)})\).

## Build and tests

Windows PowerShell (with `gfortran` on `PATH`):

```powershell
.\build.ps1
.\tests\run_tests.ps1
```

Unix-like systems (with GNU Make and OpenMP):

```bash
make                          # GNU Fortran (default)
./ugks2d cases/poiseuille_fast.namelist

make clean
make FC=ifort                 # Intel Fortran Compiler Classic
```

The Makefile selects the appropriate module and OpenMP options for `gfortran`
or `ifort`. Run `make clean` before switching compilers because their object
and module files are not interchangeable.

## Validated inputs

```text
cases/poiseuille_fast.namelist    3x100, GH16, Nm=7, t=0.2
cases/poiseuille_fast_symmetric.namelist  same case, corrected symmetric tensor
cases/poiseuille_fast_symmetric_b.namelist  same case, normalized b tensor
cases/poiseuille_steady.namelist  3x100, GH16, Nm=7, steady residual stop
cases/rt_60_fast.namelist         60x60, GH20, Nm=1, t=0.14
cases/rt_120.namelist             120x120, GH20, Nm=1, t=0.14
```

Example:

```powershell
.\ugks2d.exe .\cases\poiseuille_fast.namelist
.\ugks2d.exe .\cases\rt_60_fast.namelist
```

The default `input.namelist` is the Poiseuille `3x100` steady case using the
corrected symmetric-tensor Hermite operator.  It stops when all mass-scaled
residuals fall below `1e-7`; `maxtime=200` is the safety limit.

## Case definitions

- Poiseuille: Cartesian `0.1 x 1` domain; three streamwise cells and 100
  wall-normal cells; x-periodic; y-isothermal diffuse walls; acceleration
  strictly `(ax,ay)=(phi,0)`; `Pr=1`.
- Rayleigh--Taylor: square quarter-domain `[0,1]^2`; radial acceleration;
  left and bottom are symmetry axes; right and top are impermeable specular
  walls; `Pr=2/3`.

All specular faces use a half-range reflection: the outgoing distribution is
preserved and only the incoming velocity half-space is replaced by its
reflection.  Diffuse-wall density is computed from the discrete zero mass
flux equation.

The primitive state is `(rho,U,V,lambda)`.  This code uses `Rc=0.5`, so its
temperature convention is `lambda=1/T`, and `p=0.5*rho/lambda`.

## Key corrections

- Distinct, symmetric Gauss--Hermite roots generated by the normalized
  Hermite-root Newton recurrence used in `ugks1d`.
- Case-aware Cartesian/radial acceleration and correct normal/tangential face
  projections.
- Force-modified face trajectory uses the normal acceleration `fn`.
- Force compatibility is included in the equilibrium time derivative.
- Weighted tangential distribution moments are used in the face
  reconstruction.
- Steady residuals share a nonzero total-mass scale, so the physically zero
  Poiseuille wall-normal momentum does not make the stopping test singular.
- The transport model is case-dependent: Poiseuille uses
  `mu_ref=0.5*sqrt(pi)*Kn`, `tau=mu_ref/rho`, while RT retains its
  temperature-dependent VHS collision time.
- Every RT physical cell is updated; boundary code never overwrites the last
  physical row or column.
- `atan2(y,x)` is used on the RT symmetry axes.
